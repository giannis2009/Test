# Ezro

Link-in-bio / portfolio site for **Ezro** (VFX & video editing).

- Brand colors: `#905abd`, `#b491dc`
- Dark & light theme (follows the system setting, toggle button top right, choice is remembered)
- Static site, no build step: open `index.html` or host on GitHub Pages / Netlify / Vercel

## Editing links

All links live in the `CONFIG` object at the top of `script.js`.
Replace each `"#"` with your real URL, and set `contact` to your email (`mailto:...`) or a contact link.
Links still set to `"#"` show a "Coming soon" message when clicked.

## Files

- `index.html` — page structure and text
- `styles.css` — design, colors and both themes
- `script.js` — links, theme toggle, animations
- `assets/logo.webp`, `assets/favicon.png` — logo

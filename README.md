# Ιστοσελίδα εμπόρου αυτοκινήτων με Admin Panel

Ιστοσελίδα εμπόρου αυτοκινήτων (τύπου σελίδας εμπόρου στο car.gr), με πλήρες Admin Panel για να ανεβάζετε και να διαχειρίζεστε τα αυτοκίνητα.

## Τι περιλαμβάνει

**Δημόσιο site**
- Σελίδα εμπόρου με λογότυπο, banner, διεύθυνση, τηλέφωνα και WhatsApp
- Προτεινόμενα αυτοκίνητα
- Λίστα αγγελιών με φίλτρα (μάρκα → μοντέλο, τιμή, χρονολογία, χιλιόμετρα, καύσιμο, σασμάν, κατηγορία, αμάξωμα), αναζήτηση, ταξινόμηση και σελιδοποίηση
- Σελίδα αυτοκινήτου με gallery (thumbnails, πλήρη οθόνη, swipe στο κινητό), χαρακτηριστικά, εξοπλισμό, περιγραφή και φόρμα ενδιαφέροντος
- Ετικέτες «Κρατημένο» και «Πωλήθηκε», παρόμοια αυτοκίνητα, σελίδα επικοινωνίας με χάρτη
- Προσαρμόζεται σε κινητά

**Admin Panel (`/admin`)**
- Πίνακας ελέγχου με στατιστικά (ενεργές, πωλημένες, προβολές, αξία αποθέματος, μηνύματα)
- Προσθήκη, επεξεργασία, αντιγραφή και διαγραφή αγγελιών
- Ανέβασμα πολλών φωτογραφιών μαζί (drag & drop), αλλαγή σειράς με σύρσιμο, διαγραφή φωτογραφιών
- Γρήγορη αλλαγή κατάστασης (Ενεργή / Κρατημένο / Πωλήθηκε / Πρόχειρο) και ★ προτεινόμενο
- Μηνύματα πελατών (από τις αγγελίες και από τη σελίδα επικοινωνίας)
- Στοιχεία εμπόρου: όνομα, λογότυπο, banner, χρώμα, τηλέφωνα, ωράριο, social
- Αλλαγή ονόματος χρήστη και κωδικού

## Εγκατάσταση στην Επιφάνεια Εργασίας (Desktop)

1. Εγκαταστήστε το **Node.js** (έκδοση LTS) από https://nodejs.org. Χρειάζεται μόνο μία φορά.
2. Αποσυμπιέστε το `boost-cars.zip` στην **Επιφάνεια Εργασίας**. Εναλλακτικά, από το GitHub πατήστε **Code → Download ZIP**.
3. Ανοίξτε τον φάκελο και κάντε διπλό κλικ στο:
   - **Windows:** `START-Windows.bat`
   - **Mac:** `START-Mac.command` (την πρώτη φορά: δεξί κλικ → Άνοιγμα)
4. Ανοίγει μόνο του ο browser στο `http://localhost:3000`. Το Admin είναι στο `http://localhost:3000/admin`.

Την πρώτη φορά γίνεται αυτόματη εγκατάσταση, που χρειάζεται 1-2 λεπτά. Για να σταματήσει το site, κλείστε το μαύρο παράθυρο.

## Εκκίνηση (γραμμή εντολών)

Απαιτείται **Node.js 22.13 ή νεότερο** (η βάση SQLite είναι ενσωματωμένη στο Node, δεν χρειάζεται ξεχωριστός server βάσης).

```bash
npm install
npm start            # http://localhost:3000
npm run seed         # (προαιρετικά) προσθέτει 12 δοκιμαστικά αυτοκίνητα
```

Admin: `http://localhost:3000/admin`. Στην πρώτη εκκίνηση:
- όνομα χρήστη: `admin`
- κωδικός: `admin123`

Με την πρώτη σύνδεση το σύστημα σας ζητά υποχρεωτικά να αλλάξετε τον κωδικό.

## Ρυθμίσεις (μεταβλητές περιβάλλοντος)

| Μεταβλητή | Περιγραφή |
|---|---|
| `PORT` | Θύρα (προεπιλογή 3000) |
| `NODE_ENV=production` | Ασφαλή cookies (HTTPS) και caching |
| `ADMIN_USER`, `ADMIN_PASSWORD` | Αρχικά στοιχεία διαχειριστή (μόνο στην πρώτη εκκίνηση) |
| `SESSION_SECRET` | Μυστικό για τα sessions (αν λείπει, δημιουργείται αυτόματα) |
| `DATA_DIR` | Φάκελος βάσης δεδομένων (προεπιλογή `./data`) |
| `UPLOAD_DIR` | Φάκελος φωτογραφιών (προεπιλογή `./uploads`) |

## Ανέβασμα σε server (hosting)

Μπορεί να τρέξει σε οποιοδήποτε VPS ή υπηρεσία Node.js (π.χ. Render, Railway, DigitalOcean) πίσω από HTTPS. Κρατήστε αντίγραφα ασφαλείας (backup) των φακέλων `data/` και `uploads/`: εκεί αποθηκεύονται οι αγγελίες και οι φωτογραφίες.

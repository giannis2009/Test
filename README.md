# Boost Cars: ιστοσελίδα εμπόρου αυτοκινήτων με Admin Panel

Επαγγελματική ιστοσελίδα για έμπορο αυτοκινήτων, με πλήρες Admin Panel για να ανεβάζετε και να διαχειρίζεστε τα αυτοκίνητα.

## Δομή φακέλων

| Φάκελος | Τι περιέχει |
|---|---|
| `html/` | **HTML**: όλες οι σελίδες του site (`html/`) και του Admin (`html/admin/`). Τα κοινά κομμάτια (header, footer, κάρτα αυτοκινήτου) είναι στο `html/partials/`. |
| `css/` | **CSS**: `style.css` για το site, `admin.css` για το Admin Panel. |
| `js/` | **JS**: `site.js` για το site (μενού, φίλτρα, αγαπημένα, gallery, δόσεις), `admin.js` για το Admin (φωτογραφίες, επιβεβαιώσεις). |
| `database/` | **DATA BASE**: `schema.sql` (οι πίνακες), `database.js` (σύνδεση και ρυθμίσεις) και το αρχείο της βάσης `boostcars.db`. |
| `save-changes/` | **SAVE CHANGES**: αντίγραφα ασφαλείας (`backups/`) και φωτογραφίες που διαγράφηκαν (`deleted-photos/`). |
| `server/` | Ο server (Node.js / Express) που ενώνει τα παραπάνω. |
| `images/` | Λογότυπα και σταθερές εικόνες. |
| `uploads/` | Οι φωτογραφίες των αυτοκινήτων που ανεβάζετε από το Admin. |

Οι σελίδες στο `html/` είναι κανονικά αρχεία HTML με μερικές ετικέτες `<%= … %>`, από όπου ο server γεμίζει τα δεδομένα (π.χ. την τιμή ή το όνομα του αυτοκινήτου).

## Τι περιλαμβάνει

**Δημόσιο site**
- Αρχική με γρήγορη αναζήτηση, αριθμούς εμπιστοσύνης, αναζήτηση ανά τύπο, προτεινόμενα, νέες αφίξεις, «Γιατί εμάς» και χάρτη.
- Σελίδα αυτοκινήτων με φίλτρα, ετικέτες ενεργών φίλτρων, ταξινόμηση, προβολή πλέγμα/λίστα και φίλτρα σε συρτάρι στο κινητό.
- Σελίδα αυτοκινήτου με:
  - gallery σε πλήρη οθόνη, με swipe στο κινητό
  - βασικά στοιχεία με εικονίδια, τεχνικά χαρακτηριστικά και εξοπλισμό
  - υπολογιστή δόσεων
  - κοινοποίηση, εκτύπωση, WhatsApp και Viber
  - σταθερή μπάρα κλήσης στο κινητό
- **Αγαπημένα**: η καρδιά σε κάθε αυτοκίνητο το αποθηκεύει στη συσκευή του επισκέπτη.
- Σελίδες «Πώληση αυτοκινήτου» (φόρμα εκτίμησης), «Χρηματοδότηση», «Η εταιρεία» και «Επικοινωνία».
- SEO: sitemap.xml, robots.txt και δομημένα δεδομένα αυτοκινήτου για την Google.

**Admin Panel (`/admin`)**
- Πίνακας ελέγχου με στατιστικά, τελευταία μηνύματα και δημοφιλέστερες αγγελίες.
- Αγγελίες:
  - καρτέλες ανά κατάσταση και αναζήτηση
  - γρήγορη αλλαγή κατάστασης και ★ προτεινόμενο
  - αντιγραφή και διαγραφή
- Φόρμα αγγελίας:
  - πολλές φωτογραφίες μαζί (drag & drop), αλλαγή σειράς με σύρσιμο
  - εξοπλισμός με ένα κλικ
  - προειδοποίηση για αλλαγές που δεν έχουν αποθηκευτεί
- Μηνύματα πελατών ανά τύπο: αγγελία, επικοινωνία, πώληση, χρηματοδότηση.
- Στοιχεία εμπόρου: λογότυπα, χρώματα, κείμενα, τηλέφωνα, social, χρηματοδότηση.
- **Αποθήκευση αλλαγών**:
  - αντίγραφο ασφαλείας με ένα κλικ, και αυτόματα κάθε μέρα
  - λήψη και επαναφορά αντιγράφων

## Εγκατάσταση στην Επιφάνεια Εργασίας (Desktop)

1. Εγκαταστήστε το **Node.js** (έκδοση LTS) από https://nodejs.org. Χρειάζεται μόνο μία φορά.
2. Αποσυμπιέστε το `boost-cars.zip` στην **Επιφάνεια Εργασίας**. Εναλλακτικά, από το GitHub πατήστε **Code → Download ZIP**.
3. Ανοίξτε τον φάκελο και κάντε διπλό κλικ στο:
   - **Windows:** `START-Windows.bat`
   - **Mac:** `START-Mac.command` (την πρώτη φορά: δεξί κλικ → Άνοιγμα)
4. Ανοίγει μόνο του ο browser στο `http://localhost:30000`. Το Admin είναι στο `http://localhost:30000/admin` (χρήστης `admin`, κωδικός `admin123`, με υποχρεωτική αλλαγή στην πρώτη σύνδεση).

Την πρώτη φορά γίνεται αυτόματη εγκατάσταση, που χρειάζεται 1-2 λεπτά. Για να σταματήσει το site, κλείστε το μαύρο παράθυρο.

### Αναβάθμιση από παλαιότερη έκδοση

1. Αποσυμπιέστε τη νέα έκδοση σε **νέο** φάκελο.
2. Αντιγράψτε από τον παλιό φάκελο τους φακέλους `data` (αν υπάρχει), `database` (αν υπάρχει) και `uploads` μέσα στον νέο.
3. Ξεκινήστε κανονικά. Η παλιά βάση `data/site.db` μεταφέρεται αυτόματα στο `database/boostcars.db`.

## Εκκίνηση (γραμμή εντολών)

Απαιτείται **Node.js 22.13 ή νεότερο** (η βάση SQLite είναι ενσωματωμένη στο Node, δεν χρειάζεται ξεχωριστός server βάσης).

```bash
npm install
npm start            # http://localhost:30000
npm run seed         # (προαιρετικά) προσθέτει 12 δοκιμαστικά αυτοκίνητα
```

## Ρυθμίσεις (μεταβλητές περιβάλλοντος)

| Μεταβλητή | Περιγραφή |
|---|---|
| `PORT` | Θύρα (προεπιλογή 30000) |
| `NODE_ENV=production` | Ασφαλή cookies (HTTPS) και caching |
| `ADMIN_USER`, `ADMIN_PASSWORD` | Αρχικά στοιχεία διαχειριστή (μόνο στην πρώτη εκκίνηση) |
| `SESSION_SECRET` | Μυστικό για τα sessions (αν λείπει, δημιουργείται αυτόματα) |
| `DATA_DIR` | Φάκελος βάσης δεδομένων (προεπιλογή `./database`) |
| `UPLOAD_DIR` | Φάκελος φωτογραφιών (προεπιλογή `./uploads`) |
| `SAVE_DIR` | Φάκελος αντιγράφων ασφαλείας (προεπιλογή `./save-changes`) |

## Ανέβασμα σε server (hosting)

Μπορεί να τρέξει σε οποιοδήποτε VPS ή υπηρεσία Node.js (π.χ. Render, Railway, DigitalOcean) πίσω από HTTPS. Κρατήστε αντίγραφα των φακέλων `database/`, `uploads/` και `save-changes/`.
